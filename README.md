# Multi Algorithm Text Encryption System

A secure web application for encrypting and decrypting text using AES-256, DES, and RSA. Built with Flask.

## Features

- AES-256 CBC encryption/decryption
- DES CBC encryption (for educational purposes only)
- RSA encryption/decryption with 2048-bit keys
- SHA-256, SHA-512, and MD5 hashing
- Password generator and strength checker
- Encryption history
- Performance comparison charts
- Educational section

## Installation

```bash
pip install -r requirements.txt
```

## Running the App

```bash
python app.py
```

Then open http://localhost:5000 in your browser.
